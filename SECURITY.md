# Security Policy

beanboot is pre-1.0 software. Only the latest released version receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
[Security → Report a vulnerability](https://github.com/mszajner/beanboot/security/advisories/new).
If that is not possible, e-mail mszajner@rexoft.pl with a description, affected version and steps to reproduce.

You can expect an acknowledgement within a few days. Once a fix is available it will be released and the issue
disclosed in the release notes, crediting the reporter unless they prefer to stay anonymous.
